# Refactor-Lab3.2


What challenges did you face when refactoring your code to use Bootstrap?


The biggest challenge was making sure everything I had in my CSS page was transferable in bootstrap
I learned that most things could be transferred into bootstrap but particularly, the @media and responsiveness 
was the one thing I had issues fully transferring over.


How did using Bootstrap utility classes and components simplify your styling process?


I think the utility classes in most cases minimized the issues I had with writing vanilla css. utilizing grid and flex box 
seemed to be much simplier this time around and somewhat more intuitive designing my page.


In what scenarios might you choose not to use Bootstrap and write custom CSS instead?

I'd like to stick to using vanilla CSS when using media queries. Additionally, custom colors have to be done with vanilla CSS as
bootstrap uses pre-determined values for colors and doesn't express the full range of the color palette.
